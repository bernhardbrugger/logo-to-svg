# logo-to-svg

A Claude skill that turns a blurry raster logo (PNG/JPG, e.g. exported from Canva or generated by AI) into a clean, scalable SVG – for free, with open-source tools only.

- **Graphic:** upscaled, smoothed and traced with [potrace](https://potrace.sourceforge.net/) into smooth Bézier curves.
- **Text:** re-set with a free [Fontsource](https://fontsource.org/) font (default Montserrat), letter spacing fitted to the original, converted to paths.
- **Output:** one optimized SVG (viewBox only, 2-decimal precision, transparent background) plus an optional PNG preview.

## Install as a skill
Copy this folder into your skills directory (e.g. `~/.claude/skills/logo-to-svg/`) or upload it as a custom skill in Claude. Then just send a logo and ask Claude to vectorize it.

## Use the script directly
```bash
pip install potracer opencv-python-headless pillow numpy fonttools brotli cairosvg

python scripts/vectorize.py logo.png -o logo.svg --preview preview.png \
    --text "DR. JANE DOE" --weight 600 \
    --text "PHYSICIAN"    --weight 300
```

| Option | Description |
|---|---|
| `--text` | Text line to re-set (repeat, top to bottom). Matched to the bottom-most bands of the image. |
| `--weight` | Font weight per text line (default 400). |
| `--family` | Fontsource family, downloaded via npm (default Montserrat). |
| `--font` | Local font file per line, overrides `--family`. |
| `--color` | Override the detected color. |
| `--smooth` | Blur before tracing, in source px (default 0.6). Raise to 1.0–1.5 for jagged, non-antialiased sources. |
| `--preview` | Render a PNG preview on white. |
| `--fixed-size` | Keep width/height attributes (default: responsive, viewBox only). |

## Limits
Single color · text lines in ALL CAPS · irregularities in the source carry over · font is a close match unless you supply the original.
